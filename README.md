# FitLog — Workout Library

FitLog is a dark-themed workout management web application built for people who want to organize their daily workouts, save exercises for later, and track completed workouts. Users can browse workouts, view detailed workout information, add exercises to their daily plan, and manage saved workouts.

## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- React Toastify
- Lucide React Icons
- REST API

## Key Features

### 1. Workout Library
Browse a collection of workouts with useful information such as workout name, equipment, duration, calories burned, and rating.

### 2. Workout Details
View detailed information about each workout, including instructions, workout statistics, and available actions.

### 3. Today's Plan
Add workouts to a personal daily plan and manage the exercises you want to complete.

### 4. Saved Workouts
Save workouts for later and easily access them from the Saved tab.

### 5. Workout Completion Tracking
Mark workouts as completed and keep track of your completed exercises.

### 6. Plan Limit
Today's plan supports a maximum of five incomplete workouts. After completing a workout, another workout can be added.

### 7. Sorting
Sort workouts by duration, calories burned, or rating.

### 8. Persistent Data
Workout plan, saved workouts, and completion status are preserved using browser local storage.

### 9. Responsive Design
The application is designed to work smoothly across mobile, tablet, and desktop devices.
